# C# Collections

A study and practice guide covering collections in C# and .NET.

## Topics

- `List<T>`
- `Dictionary<TKey, TValue>`
- `HashSet<T>`
- `Queue<T>`
- `Stack<T>`
- `LinkedList<T>`
- Collection interfaces
- Choosing the right collection
- Common operations
- Practice exercises

## Requirements

- .NET SDK
- Basic knowledge of C# classes, variables, loops, and generics

## Suggested learning order

1. Understand `IEnumerable<T>` and generic collections.
2. Learn `List<T>`.
3. Learn `Dictionary<TKey, TValue>`.
4. Learn `HashSet<T>`.
5. Learn `Queue<T>` and `Stack<T>`.
6. Compare collections and select the appropriate one for a problem.
