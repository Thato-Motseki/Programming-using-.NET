# C# Collections Practice Exercises

## Exercise 1 — Student List

Create a `List<string>` containing five student names.

Requirements:

1. Add a sixth student.
2. Remove one student.
3. Sort the list.
4. Print the final list.
5. Print the number of students.

## Exercise 2 — Student Dictionary

Create a `Dictionary<int, string>` where:

- The key is a student ID.
- The value is the student's name.

Requirements:

1. Add five students.
2. Ask the user for an ID.
3. Use `TryGetValue` to find the student.
4. Display a suitable message if the ID does not exist.

## Exercise 3 — Remove Duplicates

Create a list containing duplicate integers.

Convert it into a `HashSet<int>` and display the unique values.

## Exercise 4 — Queue Simulation

Create a queue representing customers waiting at a service desk.

Add five customers and serve them one at a time using `Dequeue()`.

## Exercise 5 — Stack

Create a stack representing browser pages.

Push five pages and use `Pop()` to simulate going backwards.

## Exercise 6 — Collection Selection

For each problem, choose the best collection:

1. Store unique usernames.
2. Store employee ID and employee name.
3. Store items in the order they were added and access them by index.
4. Process jobs in arrival order.
5. Implement undo operations.

## Challenge

Build a small console-based student management system using:

- `List<T>`
- `Dictionary<TKey,TValue>`
- `HashSet<T>`

Include options to add, remove, search, and display students.
